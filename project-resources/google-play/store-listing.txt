CodeMateX is your intelligent, on-device AI coding companion, tutor, and interactive learning platform. Built for mobile engineers, computer science students, and software developers, CodeMateX runs optimized Large Language Models (LLMs) locally on your device hardware using Google's cutting-edge LiteRT runtime.

No cloud subscriptions. No telemetry. Your private prompts, learning queries, and AI chats are processed 100% on-device and never sent to cloud LLM servers.

✨ KEY HIGHLIGHTS & FEATURES

📚 Interactive Guided Courses & Syllabi
Master modern languages with structured, offline-first curriculum courses:
• Kotlin: Complete Kotlin Tour (Beginner & Intermediate) + Kotlin Foundations
• Go: Comprehensive "Go by Example" (85+ lessons) + Go Foundations
• Rust: Complete "Rust by Example" (196+ lessons) + Rust Foundations
• Python, TypeScript & Swift: Full foundational syllabi with syntax deep-dives
• Interactive Quick-Check Quizzes: Test your comprehension with instant visual validation and explanations
• Curriculum Progress Tracking: Track completed chapters, active lessons, and resume anytime
• Language Filtering: Sticky filter chips to seamlessly browse courses by language

▶️ In-App Code Execution & Terminal Runner
Run code snippets directly within guided lessons:
• Execute interactive code snippets in Kotlin, Go, Rust, Python, and TypeScript via high-speed edge sandbox execution (requires internet connection).
• Real-time terminal console output for instant verification.
• Smart Offline Mode: When disconnected from Wi-Fi or data, CodeMateX automatically adapts to offline reading mode so you can study lessons, take quizzes, and chat with your local AI tutor anywhere.

🧠 100% Local On-Device AI
• Powered by Google LiteRT-LM (supporting Gemma 2 2B, Qwen 2.5 Coder, Qwen 3, and Phi-4 Mini).
• 100% Private: All AI chats, explanations, and debugging queries run entirely on your device hardware with zero cloud LLM calls.
• Zero latency from network roundtrips.
• Context-Aware In-Lesson Chat: Ask AI Tutor questions directly about specific lesson snippets.
• Tunable AI Personas: Switch between Senior Architect, Beginner Tutor, and Interview Coach.
• Developer Profile: Inject your experience level and preferred stack into the AI's context.

🛡️ Complete Privacy & Security
• Your AI prompts, questions, and learning history never leave your device.
• No accounts, sign-ups, tracking, or personal data collection.
• Code snippet execution in the runner is sent over encrypted HTTPS solely to compile and execute, without user association or persistent storage.

📊 Real-Time Hardware Telemetry & Benchmarking
Inspect on-device LLM performance in real time:
• Hardware Backend acceleration indicators (NPU, GPU OpenCL/Vulkan, and CPU).
• Time-to-First-Token (TTFT) prefill latency in milliseconds.
• Active decode speed in tokens per second (t/s).
• Real-time model memory footprint and hyperparameter tuning (Temp, Top-K, Top-P).

🎨 Material 3 Expressive & Code Customization
• Atmospheric ambient lighting and dynamic topic visual branding.
• Syntax highlighting powered by Highlight.js with themes: Tomorrow, Atom One, GitHub, Dracula.
• Configurable code view: line numbers, font sizing, and compact density presets.
• Material You adaptive layout optimized for phones, foldables, and tablets.

⚙️ HARDWARE REQUIREMENTS
To deliver responsive on-device LLM inference, CodeMateX is optimized for modern high-performance devices:
• RAM: 8 GB RAM recommended (6 GB minimum).
• Processor: 64-bit ARM architecture (ARM64-v8a).
• Graphics: Vulkan 1.1+ compute shaders or OpenCL GPU acceleration.
