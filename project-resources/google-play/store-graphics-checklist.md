# Google Play Store: Graphic Assets & Dimensions Checklist

Refer to this checklist when preparing visual marketing assets for the Google Play Console store listing for **CodeMateX**.

---

## 1. Required Store Graphics

| Asset | Dimensions | Format | Max Size | Status in Repo |
| :--- | :--- | :--- | :--- | :--- |
| **App Icon (High-Res)** | `512 x 512 px` | 32-bit PNG (no alpha/transparency on background) | 1 MB | `app/src/main/ic_launcher-playstore.png` |
| **Feature Graphic** | `1024 x 500 px` | JPEG or 24-bit PNG (no alpha) | 15 MB | `project-resources/google-play/feature-graphic.jpg` |
| **Phone Screenshots** | Minimum `1080 x 1920 px` (16:9 or 9:16) | JPEG or 24-bit PNG | 8 MB / image | Minimum 2 required (Recommended: 4–8) |
| **7-inch Tablet Screenshots** | Minimum `1200 x 1920 px` | JPEG or 24-bit PNG | 8 MB / image | Minimum 1 required |
| **10-inch Tablet Screenshots**| Minimum `1600 x 2560 px` | JPEG or 24-bit PNG | 8 MB / image | Minimum 1 required |

## 2. Recommended Screenshot Storyboard

1. **Screenshot 1: The AI Tutor Home Screen**
   - *Headline*: "100% Private, On-Device AI Coding Tutor"
   - *Focus*: Topic cards (Kotlin, Jetpack Compose, Coroutines, System Design) and atmospheric lighting.
2. **Screenshot 2: Interactive Chat & Code Highlighting**
   - *Headline*: "Instant Code Explanation & Q&A"
   - *Focus*: Clean Markdown syntax formatting, code blocks, and copy actions.
3. **Screenshot 3: Real-Time Hardware Benchmark Panel**
   - *Headline*: "Inspect Real-Time Inference Speed & Hardware"
   - *Focus*: Sticky benchmarking dashboard showing TTFT (ms), tokens/sec throughput, and NPU/GPU badges.
4. **Screenshot 4: On-Device Model Manager**
   - *Headline*: "Download Open-Source LLMs for Offline Use"
   - *Focus*: Model cards (Gemma 2B), storage sizes, and offline status badges.
5. **Screenshot 5: Contextual Session History & Dynamic Filters**
   - *Headline*: "Organize Past Tutoring Sessions by Topic"
   - *Focus*: Horizontal filter chip row, session cards, and adaptive 2-column grid.
